# 📚 无障碍阅读伴侣（Reading Companion）

一个**纯本地运行**的网页阅读伴侣，专为注意力容易分散、读长文吃力的读者设计。
配套纸质书使用：读前看导读、读中精读跟读、读后复习巩固，把"读一本书"变成一条无障碍流水线。

**在线演示（GitHub Pages）**：https://danmoningjing.github.io/Reading-Friend/

## ✨ 功能

| 模块 | 说明 |
|---|---|
| 📖 导读卡 | 每章/卷讲什么、新人物、新地名、建议精读哪段、读完小结、自测题 |
| 🔍 精读台 | 粘贴长段落 → 自动断句 → 大字宽行距排版 → 逐句朗读跟读 → 人名/术语高亮 → 要点提取 |
| 📚 词典 | 人物 / 神祇 / 地名 / 概念，支持搜索，精读时点击即查 |
| 🏆 进度与习惯 | 每章标记、每日小目标、连续打卡、徽章体系 |
| 📅 间隔复习 | 读完自动排第 3 / 7 天复习提醒 |
| 📇 生词本 + Anki | 一键收集生词，导出 Tab 分隔 txt，导入 Anki 长期记忆 |
| ⚙️ 无障碍设置 | 字号 / 行距 / 字距 / 语速 / 浅色·护眼·夜间主题 / 专注模式 |

## 🚀 本地使用

直接双击 `index.html` 用 Chrome 或 Edge 打开即可（推荐 Edge/Chrome，朗读最稳）。
或用本地服务：

```bash
python -m http.server 8765 --directory .
# 然后访问 http://127.0.0.1:8765
```

所有数据只保存在浏览器 localStorage，不联网、无后端。

## 📁 目录结构

```
├── index.html          应用外壳（导读/精读/词典/进度/设置）
├── css/style.css       无障碍样式
└── js/
    ├── data.js         荷马史诗内容（48 卷导读卡、词典）
    ├── library.js      书库注册表
    ├── books/          每本书一个数据文件（TEMPLATE.js 为模板）
    └── app.js          应用逻辑
```

## ➕ 如何添加一本新书

1. 复制 `js/books/TEMPLATE.js` 为 `js/books/你的书.js`
2. 按文件头注释的结构填写章节（导读/人物/地名/概念/精读建议/小结/自测题）、词典、主题
3. 在 `index.html` 的 `<script>` 中加载该文件
4. 在 `js/library.js` 的 `LIBRARY` 数组里加一项

进度、词典、术语标注、复习、生词本会自动按书独立工作，无需改逻辑代码。

## 🧰 技术说明

- 纯 HTML / CSS / JavaScript，零第三方依赖，零构建
- 数据存 localStorage（不可用时自动降级为内存存储）
- 朗读使用浏览器 Web Speech API
- 已内置《荷马史诗》：伊利亚特 + 奥德赛，各 24 卷，共 96 道自测题
